## 스트릭 (주간, 최종 확정)

**최종 수정일**: 2026-08-15
**상태**: 🟢 확정 (월간 전환 검토 후 원안 유지로 최종 결론)
**담당**: 기획/디자인 - OOO / 개발 - OOO

### 0. 결정 배경

대화 초반 "이번 달 기준으로 바꾸면 어떨까"라는 아이디어로 캘린더 히트맵형,
"최근 4주 롤링"형 등 여러 대안 시안을 검토했다. 최종적으로는 **원래
`RUNNA_KR_기능정의서.md`에 정의돼 있던 주간 스트릭 디자인을 그대로
유지**하는 것으로 결론 내렸다. 월간 전환 아이디어는 채택하지 않는다.
백로그에 "🟡 월간 전환 논의 중"으로 남아있던 항목을 이 문서로 최종 종료.

### 1. 화면 구성 (홈 > 섹션 A. 주간 스트릭) — 원안 그대로 확정

- 이번 주 7일(예: 7/27~8/2)을 가로 배열 원형 인디케이터로 표시
- 각 원 하단에 날짜 표기: `7/27`, `7/28` … `8/2`
- 우측 상단에 주 단위 스트릭 뱃지: `N주 연속` (색상 고정 `#00E87A`)

**원형 인디케이터 상태**

| 상태 | 조건 | 시각 처리 |
|---|---|---|
| 미래 | 아직 오지 않은 날짜 | 빈 원 (테두리만, 낮은 opacity) |
| 미실행 | 지난 날짜인데 러닝 안 함 | 빈 원 (테두리만) |
| 달성 1~3일 연속 | 연속 러닝 1~3일째 | 초록(`#00E87A`) 채움 + 체크 아이콘 |
| 달성 4~6일 연속 | 연속 러닝 4~6일째 | 주황(`#FF5F1F`) 채움 + 체크 아이콘 |
| 달성 7일 연속 | 연속 러닝 7일 완성 | 핫핑크(`#FF2D55`) 채움 + 체크 아이콘 |

### 2. 스트릭 판정 기준

- **하루도 빠짐없이 매일 러닝해야 연속으로 인정** (기존 기능정의서 원안
  그대로 유지, 완화 정책 미적용)
- **'러닝한 날'에서 미완료 러닝은 제외한다** (2026-09-23 개정). 거리가 0 인
  기록은 `ran` 을 `true` 로 만들지 않는다 — 판정 기준과 근거는
  `records.md` §4-1 이 정본이고, 코드는 `Run.isIncomplete`.
  → 이게 없으면 연속 기록이 "매일 뛰었다"가 아니라 **"매일 START 를 눌렀다"**
  가 되어 스트릭이 동기 장치로서 의미를 잃는다.
  주의: 1분 이상 뛰었는데 GPS 를 못 잡아 0km 인 기록도 **빠진다**(2026-09-23
  개정). 실제로 뛰었어도 그날 연속이 끊긴다 — 맞바꾼 것은 `records.md` §4-1.
- 데이터 타입은 기존 `StreakDay` 그대로 사용:

```typescript
type StreakDay = {
  name: string;
  date: string;
  ran: boolean;
  consec: number | null;
  today: boolean;
  future: boolean;
};
```
