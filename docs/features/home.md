### 1. 개요

최초 사용자(러닝 기록 0건)의 홈 화면 처리 방식과, 상단 인사말 문구의
동적 로직을 정의한다.

### 2. 인사말 로직 — 시간대별로 변경 (확정)

**[제안 기본값으로 확정]** 인사말은 고정 문구가 아니라 시간대에 따라
자동으로 바뀐다.

| 시간대 | 인사말 |
|---|---|
| 05:00–10:59 | "좋은 아침이에요," |
| 11:00–16:59 | "오늘도 힘내요," |
| 17:00–20:59 | "좋은 저녁이에요," |
| 21:00–04:59 | "야간 러너시네요," |

- 기존과 동일하게 이름 + 🔥 이모지는 유지 (예: "좋은 아침이에요, 이민준님 🔥")
- **[미확정]** 위 4구간/문구는 제안값이며, 실제 카피는 마케팅/기획 톤앤매너에 맞춰 조정 가능

### 3. 빈 상태 (러닝 기록 0건인 최초 사용자)

- **여정 카드**: 시작 도시에 이미 배정되어 있으므로(가입 시 결정), 진행률
  0%가 아니라 "시작 도시 → 다음 목적지" 형태로 정상 노출됨 — 별도의
  특수 빈 상태 UI 불필요, 진행률만 0km인 상태로 자연스럽게 시작
- **스트릭 카드**: 이번 주 7개 원이 전부 "미실행"(빈 원) 상태로 보임 —
  별도 빈 상태 UI 불필요, 기존 상태 정의로 자연 커버됨
- **CTA 버튼**: "지금 달리기 시작" 문구는 기존과 동일하게 유지, 최초
  사용자에게 강조 애니메이션 등 추가 연출은 **[미확정]** (있으면 좋지만
  필수는 아님)

> 결론: 홈 화면은 여정/스트릭 둘 다 "값이 0인 정상 상태"로 자연스럽게
> 표현되므로, 별도의 전용 빈 상태 화면을 새로 만들 필요는 없다.
