## 테마 러닝 (콘텐츠 탭)

**최종 수정일**: 2026-08-15
**상태**: 🟢 카드 플로우/코스 오버레이 정책 확정 · 🟡 코스 데이터 세부 미확정
**담당**: 기획/디자인 - OOO / 개발 - OOO
**연관 문서**: `run-flow.md`(공통 러닝 로직), `online-marathon.md`(유사한
사전 정의 코스 개념이지만 순위/참가자 없음)

### 1. 개요

사전 정의된 테마 코스(예: 붕어빵런, 남산런)를 따라 뛰는 콘텐츠. 온라인
마라톤과 마찬가지로 정해진 경로가 있지만, **순위·참가자 수 등 경쟁 요소는
없다.** 코스를 정확히 따라야 하는 강제성도 없음 — "이 경로를 따라 뛰는
경험" 자체가 콘텐츠의 목적.

### 2. 사용자 시나리오

- 콘텐츠 > 테마 러닝 탭에서 카드 목록을 본다
- **카드 탭 → 모든 카드가 동일하게 상세 페이지(ThemeRunDetail)로 이동**
  (기존엔 "붕어빵런"만 상세 페이지 경유, 나머지 2개는 바로 러닝 시작 —
  이번에 전체 통일)
- 상세 페이지에서 "달리러 가기" 탭 → 달리기 화면 진입 (러닝 타입: 테마 러닝)
- 러닝 중 화면에 **사전 정의된 코스 경로가 지도 위에 오버레이 라인으로 표시**됨
  (사용자의 실시간 이동 경로인 네온그린과는 다른 색으로 구분)
- 참가자 수·순위 등은 노출되지 않음 (온라인 마라톤과의 핵심 차이)
- 종료 시 코스 이탈 여부와 무관하게 기록이 정상 저장됨 — "완주 인정/미인정"
  개념 자체가 없음 (온라인 마라톤의 GPS 엄격 매칭 로직과 다른 점)

### 3. 화면 구성

**카드 (콘텐츠 > 테마 러닝 탭)**
- 기존 정의 유지: 배경 이미지(opacity 0.6, Unsplash) + 좌측 다크 그라디언트
  + 이모지 + 코스명 + 설명 + 거리
- **카드 탭 동작만 변경**: 어떤 카드든 예외 없이 ThemeRunDetail로 이동

**ThemeRunDetail 페이지** (기존 정의 유지, 모든 코스에 동일 적용)
- 히어로 이미지 + 뒤로가기 버튼
- 코스명, 태그 행(테마러닝 · 장소 · 거리)
- 코스 소개 텍스트
- 경로 미리보기 (정적 지도 이미지 위 경로 라인)
- 하단: "뒤로가기" + "달리러 가기" 버튼

**러닝 중 화면 (테마 러닝 진입 시 추가 요소)**
- 기존 실시간 지도 + 사용자 실제 이동 경로(네온그린) 위에,
  **사전 정의된 코스 라인을 별도 색상으로 오버레이** — **[미확정]** 정확한
  색상값(예: 반투명 화이트/그레이 계열 제안, 네온그린과 명확히 구분되어야 함)

### 4. 컴포넌트 & 상태 정의

| 진입 경로 | 동작 |
|---|---|
| 카드 탭 (모든 코스 공통) | ThemeRunDetail 슬라이드 인 |
| ThemeRunDetail > 달리러 가기 | 달리기 탭 진입, 러닝 타입: 테마 러닝, 코스 오버레이 활성 |
| ThemeRunDetail > 뒤로가기 | 콘텐츠 탭으로 복귀 |

### 5. 인터랙션 / 마이크로카피

- 코스 오버레이 첫 노출 시 짧은 안내(선택) — 예: "회색 선이 추천 코스예요.
  꼭 따라가지 않아도 괜찮아요" → **[미확정]** 안내 문구 노출 여부/타이밍

### 6. 데이터 요구사항 (개발자 확인 필요 영역)

```typescript
type ThemeRun = {
  emoji: string;
  name: string;
  desc: string;
  km: number;
  img: string;
  courseRoute: { lat: number; lng: number }[];  // 신규 — 사전 정의 경로,
                                                  // 러닝 중 오버레이 렌더링용
};
```

- 온라인 마라톤과 달리 **완주 인정 로직(반경/매칭 % 등) 자체가 필요 없음**
  — 코스는 참고용 가이드일 뿐 강제되지 않음
- 코스 오버레이 렌더링: 러닝 시작 시 `courseRoute`를 클라이언트로 전달,
  지도 위에 고정 레이어로 표시. 사용자의 실시간 GPS 트랙은 별도 레이어로
  그 위에 그려짐 (두 레이어는 시각적으로 명확히 구분)
- 기존 3개 코스(붕어빵런/한강야경런/N서울타워런) 모두 `courseRoute` 데이터
  확보 필요 — 현재는 "붕어빵런"만 경로 미리보기 이미지(`image-3.png`)가
  있었고, 나머지 2개는 경로 데이터 자체가 없었을 가능성 → **[미확정]**
  나머지 코스들의 실제 경로 좌표 확보 필요 (기획 측에서 준비)

### 7. 엣지 케이스

- 사용자가 코스를 완전히 무시하고 다른 길로 뛰어도 제지하지 않음 (경쟁
  요소가 없으므로) — 기록은 "테마 러닝" 타입으로 정상 저장
- 코스 데이터(`courseRoute`)가 아직 없는 레거시/신규 카드가 있을 경우
  오버레이 없이 진행할지, 아예 카드 노출을 막을지 → **[미확정]**

### 8. 완료 조건 (Acceptance Criteria)

- [ ] 모든 테마 러닝 카드는 예외 없이 탭 시 ThemeRunDetail을 거친다
- [ ] "달리러 가기"로 진입한 러닝 화면에는 사전 정의된 코스가 오버레이로 표시된다
- [ ] 참가자 수/순위 등 경쟁 요소는 어디에도 노출되지 않는다
- [ ] 코스 이탈과 무관하게 러닝 종료 시 기록이 정상 저장된다
