### 0. 구조 요약

**전체 도시 순서는 고정**된 하나의 마스터 경로다. 각 도시는 기준점
(서울시청)으로부터의 실제 거리값(haversine 대권거리)을 가지며, 이 거리값
오름차순이 곧 고정된 여행 순서가 된다. 사용자는 가입 시점 위치에 따라
이 고정 경로 위 시작 후보 도시 중 하나에 배정되어, 그 지점부터 동일한
순서로 이어지는 도시들을 향해 나아간다.

### 4. 도시별 배경 이미지 (신규 확정)

**진행률 카드의 배경 이미지는 "다음 목적지(아직 도달하지 않은 다음 도시)"
기준으로 표시되며, 도시를 완료할 때마다 자동으로 다음 도시 이미지로
전환된다.**

- 예: 서울에서 출발해 다음 목표가 도쿄인 구간 → 도쿄를 상징하는 이미지
  (예: 도쿄타워) 노출
- 도쿄 도달 완료 → 다음 목표가 베이징으로 전환 → 배경 이미지도 베이징을
  상징하는 이미지(예: 만리장성, 자금성 등)로 자동 교체
- 각 마스터 도시는 **랜드마크 이미지 1장씩**을 매핑해 보유
- **[미확정]** 이미지는 실사진(랜드마크 사진)으로 갈지, 일러스트/아이콘
  스타일로 통일할지 — 앞서 정의한 카드 디자인 톤(다크 배경 + 그라디언트
  오버레이, `RUNNA_KR_기능정의서.md` 7-5 참조)에 맞춰 통일감 있게 선정
  필요
- 이미지 자체(실사진/일러스트 에셋)는 **콘텐츠팀에서 별도 소싱/제작
  필요** — 저작권이 있는 사진을 함부로 쓸 수 없으므로, 라이선스가 확인된
  스톡 이미지 구매 또는 자체 제작 일러스트 권장

### 6. 데이터 요구사항 (개발자 확인 필요 영역)

```typescript
type MasterCity = {
  id: string;
  name: string;
  countryName: string | null;
  lat: number;
  lng: number;
  cumulativeKm: number;
  isStartCandidate: boolean;
  backgroundImageUrl: string;   // 신규 — 도시별 랜드마크 이미지
};

type JourneyState = {
  assignedStartCityId: string;
  startResolvedFromGPS: boolean;
  startedAt: string;
  totalDistanceKm: number;
  currentMilestoneIndex: number;
};
```

- 사용자의 절대 위치 = `assignedStartCity.cumulativeKm + totalDistanceKm`
- 시작 도시보다 앞선 도시는 배지 지급 대상에서 제외
- 진행률 카드 배경 이미지 렌더링 로직: `masterCities[currentMilestoneIndex + 1].backgroundImageUrl` (다음 목적지 기준)
- 모든 마스터 도시에 이미지가 매핑돼 있어야 전 구간에서 배경이 비지 않음 — **[미확정]** 이미지가 아직 준비 안 된 도시는 어떤 기본 이미지로 대체할지(플레이스홀더)
