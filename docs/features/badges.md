## 배지 시스템 (Badges)

**최종 수정일**: 2026-08-15
**상태**: 🟢 3종 배지 조건 확정 · 아이콘/디자인 콘텐츠는 별도 작업
**담당**: 기획/디자인 - OOO / 개발 - OOO
**연관 문서**: `theme-running.md`, `online-marathon.md`, `records.md`, `journey.md`

### 1. 개요

프로필 탭의 배지 컬렉션에 지급되는 3가지 배지 유형을 정의한다:
테마 코스 완주 배지, 월별 온라인 마라톤 배지, 여정 마일스톤 배지.

### 2. 사용자 시나리오

- 테마 러닝으로 특정 코스의 목표 거리 80% 이상을 뛰고 종료하면 해당 코스
  전용 배지를 획득
- 온라인 마라톤에서 GPS 인정된 완주 기록을 남기면 그 회차 전용 배지를 획득
  (예: "2026년 9월 온라인 마라톤")
- 누적 거리가 여정의 다음 도시 기준을 넘으면 해당 도시 배지를 획득
- 프로필 > 배지 컬렉션에서 획득한 배지는 이모지로, 미획득은 잠금 아이콘
  으로 표시 (기존 정의 유지)

### 3. 배지 종류 및 획득 조건

| 유형 | 예시 명칭 | 획득 조건 | 재획득 여부 |
|---|---|---|---|
| 테마 코스 완주 | "붕어빵런 완주", "남산런 완주", "고구마런 완주" | 해당 테마 코스로 러닝 종료, **목표 거리의 80% 이상** 달성 | 최초 1회만 지급, 이후 반복 러닝은 배지에 영향 없음 |
| 월별 온라인 마라톤 | "2026년 9월 온라인 마라톤" | 해당 회차 챌린지에서 **GPS 인정된 완주 기록** 보유 (`records.md`의 `gpsVerified: true` 기준) | 회차(challenge)별로 각각 별도 배지 — 같은 코스라도 다른 달이면 다른 배지 |
| 여정 마일스톤 | "부산 도착", "도쿄 도착" | 전체 누적 거리가 해당 도시의 `cumulativeKm` 도달 (`journey.md` 참조) | 도시별 1회만 |

### 4. 컴포넌트 & 상태 정의

**프로필 배지 컬렉션 표시 방식 변경**

- 기존 기능정의서: "N / 12 획득" 처럼 **총 배지 수가 12개로 고정**돼 있었음
- **변경**: 테마 코스가 늘어나거나, 매달 새 마라톤 회차가 열리거나, 여정에
  새 도시가 추가될 때마다 총 배지 수가 계속 늘어나는 **동적 값**으로 전환
  → "N / (현재 전체 배지 종류 수)" 형태로 항상 실시간 계산

### 5. 데이터 요구사항 (개발자 확인 필요 영역)

**`Badge` 타입 확장 필요**:

```typescript
type BadgeType = "theme_course" | "marathon_monthly" | "milestone_city";

type Badge = {
  id: string;
  type: BadgeType;
  emoji: string;
  name: string;      // "붕어빵런 완주" / "2026년 9월 온라인 마라톤" / "부산 도착"
  earned: boolean;
  earnedAt?: string;
  refId: string;      // type별로 참조 대상이 다름 (아래 참조)
};
```

| `type` | `refId`가 가리키는 것 |
|---|---|
| `theme_course` | `ThemeRun.id` |
| `marathon_monthly` | `Marathon.id` (회차 ID, `courseId`가 아님 — 같은 코스라도 회차마다 별도 배지) |
| `milestone_city` | `MilestoneCity.id` |

**연관 타입 보강 필요**

- `ThemeRun` 타입에 고유 `id` 필드 신규 추가 (`theme-running.md`의 기존
  타입엔 없었음, name만으로는 장기적으로 불안정한 키)
- 배지 산정 트리거: 러닝 종료(STOP) 시점마다 서버(또는 클라이언트)가
  1) 방금 종료한 러닝이 테마/온라인 조건을 만족하는지, 2) 갱신된
  누적거리가 새 마일스톤을 넘었는지 함께 체크 — **[미확정]** 이 계산을
  클라이언트에서 즉시 할지, 서버 배치로 처리할지

### 6. 엣지 케이스

- 테마 코스의 목표 거리(`km`) 자체가 나중에 변경되면, 이미 지급된 배지의
  소급 취소는 하지 않음(지급 시점 기준으로 고정)
- 같은 달에 마라톤이 여러 개 열리는 경우(예: 5K 챌린지 + 하프마라톤 동시
  진행) → 각각 별도 `Marathon.id`이므로 자연히 별도 배지로 처리됨, 별도
  로직 불필요
- 80% 거리 기준을 살짝 밑도는 경우(예: 79%) 안내 문구 필요 여부 →
  **[미확정]**
