|------|-------|--------|--------|
| 01 | `home` | 홈 | Home |
| 02 | `run` | 달리기 | Play |
| 03 | `records` | 기록 | BarChart2 |
| 04 | `content` | 콘텐츠 | Map |
| 05 | `profile` | 프로필 | User |

## 3. 네비게이션 플로우

### 3-1. 전체 화면 전환 다이어그램

```
┌──────────────────────────────────────────────────────┐
│                   하단 탭 바                          │
│  [홈] ──────── [달리기] ── [기록] ── [콘텐츠] ── [프로필] │
└──────────────────────────────────────────────────────┘

홈
 └─ [지금 달리기 시작] ──────────────────────────────────→ 달리기 (러닝 타입: 일반 러닝)

콘텐츠 > 테마 러닝
 └─ 붕어빵런 카드 탭 ──→ ThemeRunDetail 슬라이드 인
       └─ [달리러 가기] ─────────────────────────────────→ 달리기 (러닝 타입: 테마 러닝)
       └─ [뒤로가기] ────────────────────────────────────→ 콘텐츠 > 테마 러닝 (복귀)
 └─ 그 외 카드 탭 ──────────────────────────────────────→ 달리기 (러닝 타입: 테마 러닝)

콘텐츠 > 온라인 마라톤
 └─ [참가하기] 탭 ───────────────────────────────────────→ 달리기 (러닝 타입: 온라인 마라톤)

달리기
 └─ [START] ──→ 러닝 중 화면
       └─ [PAUSE] ──→ 일시정지 화면
             └─ [RESUME] ──→ 러닝 중 화면 (재개)
             └─ [STOP] ──→ RunDetailView (종료 결과)
       └─ [STOP] ──→ RunDetailView (종료 결과)
             └─ [×] ──────────────────────────────────────→ 달리기 (idle 초기화)

기록
 └─ 기록 카드 탭 ──→ RunDetailView (기록 상세)
       └─ [←] ────────────────────────────────────────────→ 기록 목록 (복귀)
```

### 3-2. 러닝 타입 결정 규칙

러닝 타입은 **달리기 화면에서 직접 변경할 수 없다.** 진입 경로에 따라 자동으로 설정된다.

| 진입 경로 | 설정되는 러닝 타입 |
|-----------|-----------------|
| 홈 > [지금 달리기 시작] | 일반 러닝 |
| 하단 탭 > [달리기] 직접 탭 | 일반 러닝 |
| 콘텐츠 > 테마 러닝 > 카드 탭 | 테마 러닝 |
| 콘텐츠 > 테마 러닝 > ThemeRunDetail > [달리러 가기] | 테마 러닝 |
| 콘텐츠 > 온라인 마라톤 > [참가하기] | 온라인 마라톤 |

## 4. 화면별 기능 명세

---

### 4-1. 홈 (Home)

**목적:** 오늘의 러닝 동기 유발, 주간 스트릭 현황 확인, 달리기 진입점 제공

---

#### 섹션 A. 주간 스트릭

**표시 구조**
- 이번 주 날짜 범위(예: `7/27~8/2`) 7일을 가로 배열의 원형 인디케이터로 표시
- 각 원 하단에 날짜 표기: `7/27`, `7/28`, `7/29`, `7/30`, `7/31`, `8/1`, `8/2`
- 우측 상단에 주 단위 스트릭 뱃지: `N주 연속` (색상 고정: `#00E87A`)

**원형 인디케이터 상태**

| 상태 | 조건 | 시각 처리 |
|------|------|----------|
| 미래 | 아직 오지 않은 날짜 | 빈 원 (테두리만, 낮은 opacity) |
| 미실행 | 지난 날짜인데 러닝 안 함 | 빈 원 (테두리만) |
| 달성 1~3일 연속 | 연속 러닝 1~3일째 | 초록(`#00E87A`) 채움 + 체크 아이콘 |
| 달성 4~6일 연속 | 연속 러닝 4~6일째 | 주황(`#FF5F1F`) 채움 + 체크 아이콘 |
| 달성 7일 연속 | 연속 러닝 7일 완성 | 빨강(`#EF4444`) 채움 + 체크 아이콘 |

---

#### 섹션 B. CTA 버튼

| 버튼 | 동작 |
|------|------|
| 지금 달리기 시작 | 달리기 탭으로 이동 + 러닝 타입을 `일반 러닝`으로 설정 |

---

### 4-2. 달리기 (Run)

**목적:** 러닝 세션 실행, 실시간 트래킹, 결과 저장

---

#### 섹션 A. 러닝 타입 카드 (출발 전 화면 상단 고정)

- 현재 설정된 러닝 타입을 읽기 전용으로 표시
- 탭에 직접 진입하거나 홈 CTA로 오면 `일반 러닝`
- 콘텐츠 탭에서 특정 코스/대회를 선택해서 오면 해당 타입으로 설정됨
- 이 화면 내에서 타입 변경 불가

---

#### 섹션 B. 날씨 / 미세먼지 카드 (출발 전 화면)

**날씨 카드**
- 현재 날씨 아이콘 + 기온(°C) + 체감온도 표시

**미세먼지 카드**
- `좋음 / 보통 / 나쁨 / 매우나쁨` 4단계 상태 바로 시각화
- 배경 컬러 활성화 조건:
  - `나쁨`: 주황 계열 배경
  - `매우나쁨`: 빨강 계열 배경
  - `좋음` / `보통`: 중립(무채색) 배경 유지

---

#### 섹션 C. 러닝 세션 상태 머신

```
[idle] ──[START]──→ [running] ──[PAUSE]──→ [paused]
                         ↑                     |
                         └────[RESUME]──────────┘
                         |
                    [STOP] ↓
                      [stopped]
```

**각 상태별 화면**

**`idle` (출발 전)**
- 러닝 타입 카드
- 날씨 / 미세먼지 카드
- `START` 버튼 (네온 그린, 전체 너비)

**`running` (달리는 중)**
- 실시간 지도 화면 (GPS 경로 실시간 표시)
- 상단 오버레이: 현재까지 달린 거리 / 현재 페이스 / 경과 시간
- 하단 버튼: `PAUSE` (일시정지) + `STOP` (종료)
- 수집 데이터: GPS 좌표 배열, 타임스탬프, 거리(누적), 페이스(실시간)

**`paused` (일시정지)**
- 동일 지도 화면 (경로 트래킹 중단)
- 하단 버튼: `RESUME` (재개) + `STOP` (종료)
- 타이머 일시 중지 (거리·시간 누적 중단)

**`stopped` (종료)**
- **RunDetailView 컴포넌트** 렌더 (→ 섹션 5 참조)
- `×` 버튼 탭 시: 달리기 탭 `idle` 상태로 초기화

---

#### 섹션 D. 러닝 종료 시 저장되는 데이터

달리기를 STOP하는 순간 아래 데이터가 기록된다.

| 필드 | 타입 | 설명 | 저장 시점 |
|------|------|------|----------|
| `date` | string | 러닝 날짜 (`MM.DD`) | STOP 시 |
| `day` | string | 요일 (`월`~`일`) | STOP 시 |
| `km` | number | 총 달린 거리 (km) | STOP 시 |
| `pace` | string | 평균 페이스 (`M'SS"`) | STOP 시 |
| `dur` | string | 총 소요 시간 (`HH:MM`) | STOP 시 |
| `kcal` | number | 소모 칼로리 | STOP 시 |
| `type` | RecordType | 러닝 타입 (`일반`/`테마`/`온라인`) | 진입 시 결정 |
| `year` | number | 연도 | STOP 시 |
| `month` | number | 월 | STOP 시 |
| `photoUrl` | string? | 사진 URL (선택적) | 사용자가 업로드 시 |

**사진 업로드 플로우**
1. RunDetailView(stopped) 화면에서 사진 업로드 영역 탭
2. 기기 갤러리에서 사진 선택
3. 사진이 히어로 배경으로 즉시 반영 (미리보기)
4. 저장 완료 → `photoUrl` 필드에 저장

### 4-3. 기록 (Records)

**목적:** 누적 러닝 히스토리 열람 및 개별 기록 상세 확인

---

#### 섹션 A. 전체 요약 통계 (상단 고정)

| 순서 | 항목 | 단위 | 집계 대상 |
|------|------|------|----------|
| 1 | 총 거리 | km | 현재 필터 기준 전체 합산 |
| 2 | 총 시간 | h·m | 현재 필터 기준 전체 합산 |
| 3 | 총 횟수 | 회 | 현재 필터 기준 카운트 |

---

#### 섹션 B. 타입 필터

| 필터값 | 표시 대상 |
|--------|----------|
| `전체` | 모든 기록 |
| `일반` | type = "일반" 기록만 |
| `테마` | type = "테마" 기록만 |
| `온라인` | type = "온라인" 기록만 |

- 필터 변경 시 → 요약 통계 및 목록 즉시 업데이트
- 기본 선택값: `전체`

---

#### 섹션 C. 월별 스티키 헤더

- 필터 바 아래, 기록 목록 내 월이 바뀌는 경계마다 삽입
- 스크롤 중 현재 월 헤더가 상단에 고정 (sticky)
- 형식: `YYYY년 MM월` (예: `2026년 06월`)

---

#### 섹션 D. 러닝 기록 카드

카드에 표시되는 정보:

| 필드 | 예시 |
|------|------|
| 날짜 / 요일 | `06.30 화` |
| 러닝 타입 뱃지 | `일반` / `테마` / `온라인` |
| 거리 | `8.4km` |
| 페이스 | `5'12"` |
| 소요 시간 | `43:41` |
| 칼로리 | `498kcal` |

**카드 탭 동작**
- 탭 → RunDetailView 슬라이드 인 (기록 상세 모드)
- 사진이 있는 기록 → 사진 모드로 렌더
- 사진이 없는 기록 → 지도 모드로 렌더

---

#### 섹션 E. RunDetailView (기록 상세)

- `closeIcon = "back"` (← 버튼)
- ← 탭 → 기록 목록으로 복귀 (슬라이드 아웃)

---

### 4-4. 콘텐츠 (Content)

**목적:** 이색 테마 러닝 코스 탐색 및 온라인 마라톤 참가

서브 탭:

| 서브 탭 | 설명 |
|--------|------|
| 테마 러닝 | 테마 러닝 코스 카드 목록 |
| 온라인 마라톤 | 진행 중·예정 대회 카드 목록 |

---

#### 섹션 A. 테마 러닝 탭

**카드 구성**

| 영역 | 내용 |
|------|------|
| 배경 이미지 | Unsplash 사진 (opacity 0.6) + 좌측 다크 그라디언트 |
| 이모지 + 코스명 | 예: 🐟 붕어빵런 |
| 코스 설명 | 한 줄 설명 |
| 거리 | km 단위 |

**카드 탭 동작**

| 카드 | 탭 동작 |
|------|--------|
| 붕어빵런 | ThemeRunDetail 슬라이드 인 (상세 설명 페이지) |
| 한강야경런 | 달리기 탭으로 이동 (러닝 타입: 테마 러닝) |
| N서울타워런 | 달리기 탭으로 이동 (러닝 타입: 테마 러닝) |

---

#### 섹션 B. ThemeRunDetail 페이지 (붕어빵런)

오른쪽에서 슬라이드 인 되는 전체 화면 오버레이.

**페이지 구성 (위→아래)**

| 섹션 | 내용 |
|------|------|
| 히어로 이미지 | 배경 사진 전체 너비 + 다크 오버레이 |
| 뒤로가기 버튼 | 히어로 좌상단, 탭 시 콘텐츠 탭으로 복귀 |
| 코스명 | 히어로 하단: `붕어빵런` |
| 태그 행 | `테마 러닝` · `어린이대공원` · `5.2km` |
| 코스 소개 | 텍스트 설명 (어린이대공원 경로가 붕어빵 모양을 그린다는 내용) |
| 경로 미리보기 | 실제 GPS 경로 지도 이미지 (`image-3.png`) |
| 하단 버튼 행 | `뒤로가기` (테두리) + `달리러 가기` (초록 그라디언트) — 동일 크기(flex-1) |

**하단 버튼 동작**

| 버튼 | 동작 |
|------|------|
| 뒤로가기 | ThemeRunDetail 닫기 → 콘텐츠 > 테마 러닝으로 복귀 |
| 달리러 가기 | 달리기 탭으로 이동 (러닝 타입: `테마 러닝`) |

---

#### 섹션 C. 온라인 마라톤 탭

**카드 구성**

| 영역 | 내용 |
|------|------|
| 히어로 (고정 높이) | 장소 배경 사진 (opacity 0.7) + 좌측 다크 그라디언트 오버레이 |
| 위치 | 📍 예: 서울 · 반포한강공원 |
| 대회명 | 예: 7월 온라인 하프마라톤 |
| 목표 거리 / 코스 | 예: 21.1km · 평지 코스 |
| D-day 뱃지 | `D-12` (초록) / `종료` (회색) |
| 참가자 수 | 예: 👤 1,204명 참여 중 |
| 내 순위 / 기록 | 참가한 경우만 표시: 예: 🏆 현재 1위 · 1:31:22 |
| 상금·포인트 | 예: 🥇 금메달 + 5,000P |
| 버튼 | 미참가: `참가하기` / 참가 중: 참가 중 표시 |

**등록된 대회 목록**

| 대회명 | 거리 | 장소 | D-day | 참가 여부 | 배경 이미지 |
|--------|------|------|-------|---------|------------|
| 7월 온라인 하프마라톤 | 21.1km | 서울 · 반포한강공원 | D-12 | 참가 중 (현재 1위) | 반포한강공원 야경 |
| 6월 온라인 10K 마라톤 | 10km | 서울 · 광화문 광장 | D-28 | 미참가 | 광화문 광장 |

### 4-5. 프로필 (Profile)

**목적:** 사용자 정보 확인, 누적 통계 열람, 배지 컬렉션, 앱 설정 접근

---

#### 섹션 A. 사용자 카드

| 요소 | 내용 |
|------|------|
| 아바타 | 이모지 아이콘 (예: 🏃) |
| 이름 | 예: 이민준 |
| 서브텍스트 | `RUNNA KR` |

---

#### 섹션 B. 통계 요약 (3칸 그리드)

| 순서 | 항목 | 단위 |
|------|------|------|
| 1 | 총 거리 | km |
| 2 | 총 시간 | h |
| 3 | 총 횟수 | 회 |

## 5. 공유 컴포넌트

### RunDetailView

달리기 종료 결과 화면과 기록 상세 화면에서 동일하게 사용되는 컴포넌트.

**Props**

| prop | 타입 | 필수 | 설명 |
|------|------|------|------|
| `date` | string | ✓ | 러닝 날짜 (예: `"08.01"`) |
| `km` | number | ✓ | 달린 거리 |
| `pace` | string | ✓ | 평균 페이스 (예: `"6'28\""`) |
| `dur` | string | ✓ | 소요 시간 (예: `"18:43"`) |
| `kcal` | number | ✓ | 소모 칼로리 |
| `onClose` | () => void | ✓ | 닫기 버튼 콜백 |
| `initialPhotoUrl` | string | - | 업로드된 사진 URL (없으면 지도 모드) |
| `closeIcon` | `"back"` \| `"x"` | - | 닫기 버튼 아이콘 (기본값: `"back"`) |

**렌더 모드**

| 조건 | 모드 | 레이아웃 |
|------|------|----------|
| `initialPhotoUrl` 있음 | **사진 모드** (Strava 스타일) | 사진 풀블리드 배경 · 좌하단 KM/페이스/타임 · 우하단 경로 SVG · RUNNA KR 워터마크 |
| `initialPhotoUrl` 없음 | **지도 모드** (Nike 스타일) | 다크 격자 배경 + 라디얼 그린 글로우 · 중앙 경로 SVG(180×180) · 하단 거리 · 페이스/타임/칼로리 행 |

**사용처**

| 화면 | `closeIcon` | `initialPhotoUrl` | 닫기 동작 |
|------|------------|-------------------|----------|
| 달리기 탭 (stopped) | `"x"` | 방금 업로드한 사진 URL | idle 상태로 초기화 |
| 기록 탭 (상세) | `"back"` | 해당 기록의 `photoUrl` | 기록 목록으로 복귀 |

### 7-5. 주요 UI 패턴

**카드**
- 배경: `--card` (`#0D1018`)
- 테두리: `border-border` (`rgba(255,255,255,0.07)`)
- 모서리: `rounded-xl` (12px) 또는 `rounded-2xl` (16px)

**이미지 위 텍스트 가독성 확보**
- 좌측 텍스트 + 우측으로 fade out하는 수평 그라디언트 오버레이 사용
- 예: `linear-gradient(to right, rgba(7,9,17,0.92) 0%, rgba(7,9,17,0.6) 55%, rgba(7,9,17,0.15) 100%)`

**슬라이드 인 페이지 전환**
- `motion/react` AnimatePresence 사용
- 진입: `x: "100%"` → `x: 0` (오른쪽에서 슬라이드 인)
- 퇴장: `x: 0` → `x: "100%"` (오른쪽으로 슬라이드 아웃)

**버튼**
- 주요 액션: 네온 그린 그라디언트 (`#00A854` → `#00E87A`)
- 보조 액션: 테두리만 있는 고스트 버튼 (`border-border`)
- 위험 액션 (회원탈퇴): 낮은 opacity 텍스트 링크
