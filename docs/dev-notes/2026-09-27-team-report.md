## 2. 지금 되는 것

### 달리기 (핵심)
- START → 3초 카운트다운 → 추적 → 일시정지/재개 → 종료까지 **상태 머신 완성**
- 실시간 지도(Google Maps, 다크 스타일) + 경로 선 그리기
- **화면을 끄거나 앱을 내려도 계속 추적** (안드로이드 포그라운드 서비스 + 알림)
- 앱이 강제 종료돼도 **진행 중이던 러닝을 복원**(스냅샷 저장)
- GPS 튐 거르기(사람이 못 내는 속도 · 최소 이동거리) · 신호 끊김 구간 처리
- 1km 구간별 페이스 자동 계산 · 대표 이미지(경로 그림 또는 직접 찍은 사진)
- 위치 권한이 없을 때 **3단계 안내 모달**(미허용 / 거부 / 영구 차단)
- **절전 모드 안내** — 구형 기기(Android 9 이하)에서 절전이 켜져 있으면 START 전에 알린다
- **음성 안내** — 출발 · 1km마다 · 종료를 읽어준다 (아래 참조)

### 홈
- 누적 거리로 진행되는 **지구 한 바퀴 여정** — 서울0 → 인천27 → 전주194 → 부산325km
  → 해외 G20 수도 18개(베이징952km ~ 부에노스아이레스19,432km)
- 도시 도달 시 **배경 이미지 전환** (22개 도시 이미지 투입 — 단 아래 4번 참조)
- 주간 스트릭 · 시간대별 인사말 · 첫 사용자 빈 상태

### 기록
- 목록 · 요약 · 필터 · 상세(지도 경로 / 사진 토글 / 1km 구간 페이스)
- 러닝 타입 뱃지 · 빈 상태 · **오프라인에서도 조회 가능**

### 프로필
- 계정 정보 · 닉네임 변경(2~12자) · 권한 상태 표시 · 로그아웃 · 회원탈퇴
- 배지 컬렉션 화면 (아이콘 에셋은 미정 — 4번 참조)

### 공통 / 기반
- **구글 로그인** (Supabase). 세션 30일 유지
- **local-first**: 로컬 DB(drift)가 1차 진실 소스 → 서버 업로드는 뒤따라 처리.
  **비행기 모드에서 뛰어도 기록은 안 사라지고**, 연결되면 자동 업로드
- 오프라인 배너 · 로딩 스켈레톤 · 에러 + 재시도 버튼
- 디자인 토큰(다크 테마·네온그린) 코드 반영 완료

## 3. 실기기 검증 상태

| 확인됨 | 아직 안 눌러본 것 |
|---|---|
| 지도·경로·다크 스타일 | 닉네임 변경 후 홈 인사말 반영 |
| 백그라운드 추적 · 종료 후 복원 | 최초 사용자 0 상태 (빈 DB 기기에서) |
| 로그아웃 → 재로그인 | 권한 화면 껐다 켜기 |
| 알림 아이콘 | 회원탈퇴(전체 기기 로그아웃) |
| GPS 실측 3대 비교 + 절전 대조 측정 | 오프라인에서 뛰고 끝내기 |
| **절전 모드 안내** (켜짐·꺼짐 양쪽) | |
| **음성 안내 5문장** (기기에서 청취) | |

밀린 기록의 **자동 업로드는 9/27에 확인됐다** — 9/26 저녁 기록이 다음 날 아침
접속 때 서버로 올라갔고, 로컬 17건 전부 업로드 완료 상태다.

### GPS 정확도 — 원인이 밝혀졌다

9/26에 우리 앱 · 아이폰 · 삼성헬스로 같은 코스를 동시 측정했다.
**거리는 맞는데**(우리 2.41km vs 아이폰 2.39km, 0.84% 차이) **지도에 그려지는
경로가 실제와 달랐다.**

**9/27에 같은 기기에서 절전 모드만 끄고 다시 측정해 원인을 확정했다.**

| 항목 | 절전 **OFF** | 절전 **ON** |
|---|---|---|
| 정확도 중앙값 | **4m** | 20m (최대 533m) |
| 좌표 간격 | **5초 고정** | 최대 **205초 끊김** |
| 경로가 튄 구간 | **0건** | 19건 (최대 457m) |

**앱 결함이 아니라 OS 동작이었다.** Android 9 이하는 절전 모드에서 화면을 끄면
위치 서비스를 정지시키고, 앱이 막을 수 없다. Strava도 같은 문제를 도움말로
안내한다. 그래서 **9/27에 START 전 안내를 넣었다.**

거리 계산도 제대로 동작하고 있었다 — 끊긴 구간 825m를 자동으로 제외하고 있었고,
그래서 다른 앱과 거리가 맞았다.

> **남은 것**: 거리가 확정된 트랙에서 재측정해야 절대 정확도가 판정된다.

## 6. 음성 안내 — 구현 완료 (9/27)

출발할 때와 1km마다, 종료할 때 음성으로 알려준다. **기기에 내장된 음성 합성을
쓰므로 추가 서버도, 비용도, 네트워크도 필요 없다.** 오프라인 러닝에서도 동작한다.

| 시점 | 멘트 | 길이 |
|---|---|---|
| 출발 | "러닝을 시작합니다" | 1.4초 |
| 1km | "1킬로미터, 6분 28초" | 2.2초 |
| 2km부터 | "2킬로미터, 구간 6분 28초, 평균 6분 41초" | 4.3초 |
| 종료 | "러닝을 종료합니다. 전주까지 142.6킬로미터 남았습니다" | 5.1초 |
| 도시 도착 | "러닝을 종료합니다. 전주에 도착했습니다" | 3.4초 |

**종료 때 거리·시간을 읽지 않는다.** 요약 화면에 크게 떠 있기 때문이다. 대신
**여정 잔여 거리**를 읽는다 — 그 화면에 없는 유일한 정보이고, 방금 뛴 거리가
"지구 한 바퀴" 어디에 쌓였는지 알려주는 자리다. **도시에 도착한 날은 멘트가
바뀐다.** 22개 도시에서 딱 한 번씩만 들린다.

목소리는 **기기 설정을 따라간다** — 앱이 음성을 따로 싣지 않는다. 삼성헬스도
같은 방식이다.

**남은 것**: 읽는 속도가 살짝 빠르다는 의견이 있어 **다른 기기에서 더 들어본 뒤**
정한다. 음소거 스위치와 음악 볼륨 처리도 남아 있다. **iOS는 Mac이 없어
검증하지 못했다.**
