01 — 지금 되는 것

실기기에 설치하면 이만큼 동작한다

5개 탭과 하위 화면이 전부 존재한다. 빈 화면은 없다. 개발 물량이 가장 많이 들어간 곳은 달리기(커밋 17개) → 프로필 9 → 기록 8 → 홈 6 순이다.

달리기커밋 19

  • START → 3초 카운트다운 → 추적 → 일시정지·재개 → 종료까지 상태 머신 완성
  • 실시간 지도(Google Maps 다크 스타일)에 경로 선 그리기
  • 화면을 끄거나 앱을 내려도 계속 추적 — 포그라운드 서비스 + 상태바 알림
  • 앱이 강제 종료돼도 진행 중이던 러닝을 복원
  • GPS 튐 거르기(사람이 못 내는 속도·최소 이동거리), 신호 끊김 구간 처리
  • 1km 구간별 페이스 계산 · 대표 이미지(경로 그림 또는 직접 찍은 사진)
  • 위치 권한이 없을 때 3단계 안내(미허용 / 거부 / 영구 차단)
  • 절전 모드 안내 — 구형 기기에서 절전이 켜져 있으면 START 전에 알린다
  • 음성 안내 — 출발 · 1km마다 · 종료를 읽어준다 (06 참조)

홈커밋 6

  • 누적 거리로 진행되는 지구 한 바퀴 여정 — 국내 4개 + 해외 G20 수도 18개
  • 도시에 도달하면 카드 배경 이미지가 바뀐다 (22개 투입 · 최종 에셋 대기)
  • 주간 스트릭 · 시간대별 인사말 · 첫 사용자 빈 상태

기록커밋 8

  • 목록 · 요약 · 필터 · 상세(지도 경로 ↔ 사진 토글 · 1km 구간 페이스)
  • 러닝 타입 뱃지 · 빈 상태 · 오프라인에서도 조회된다

프로필커밋 9

  • 계정 정보 · 닉네임 변경(2~12자) · 권한 상태 표시 · 로그아웃 · 회원탈퇴
  • 배지 컬렉션 화면 — 아이콘 에셋만 비어 있다

기반공통

  • 구글 로그인(Supabase) · 세션 30일 유지
  • local-first — 로컬 DB가 1차 진실 소스, 서버 업로드는 뒤따라 처리. 비행기 모드에서 뛰어도 기록이 안 사라지고 연결되면 자동 업로드된다
  • 오프라인 배너 · 로딩 스켈레톤 · 에러 + 재시도
  • Supabase users · runs 테이블 + 대표사진 저장소(RLS 적용)

03 — 검증 상태

확인한 것과 아직 안 눌러본 것

갤럭시 S24 · 갤럭시 노트8 두 대에 설치해 실측까지 진행했다.

확인됨

  • 지도 · 경로 · 다크 스타일
  • 백그라운드 추적 · 종료 후 복원
  • 로그아웃 → 재로그인
  • 상태바 알림 아이콘
  • GPS 실측 3대 비교 + 절전 대조 측정
  • 절전 모드 안내 (켜짐·꺼짐 양쪽)
  • 음성 안내 5문장 (기기에서 청취)

아직 안 눌러본 것

  • 닉네임 변경 후 홈 인사말 반영
  • 최초 사용자 0 상태(빈 DB 기기)
  • 권한 화면 껐다 켜기
  • 회원탈퇴(전체 기기 로그아웃)
  • 오프라인에서 뛰고 끝내기

밀린 기록의 자동 업로드는 9/27에 확인됐다 — 9/26 저녁 기록이 다음 날 아침 접속 때 올라갔고, 로컬 17건 전부 업로드 완료다.

위치 정확도 중앙값. 절전 ON 에서는 최대 205초 끊김과 457m 점프가 있었고, OFF 에서는 둘 다 0건이다.

앱 결함이 아니라 OS 동작이었다. Android 9 이하는 절전 모드에서 화면을 끄면 위치 서비스를 정지시키고, 앱이 막을 수 없다. Strava도 같은 문제를 도움말로 안내한다. 그래서 9/27에 START 전 안내를 넣었다. 거리 계산도 제대로 동작하고 있었다 — 끊긴 구간 825m를 자동으로 제외하고 있었고, 그래서 다른 앱과 거리가 맞았다.

남은 것: 거리가 확정된 트랙에서 재측정해야 절대 정확도가 판정된다.

06 — 9/27 추가

러닝 음성 안내

출발할 때와 1km마다, 종료할 때 음성으로 알려준다. 기기에 내장된 음성 합성을 쓰므로 추가 서버도, 비용도, 네트워크도 필요 없다. 오프라인 러닝에서도 동작하고, 화면을 꺼도 그대로 말한다.

종료할 때 거리·시간을 읽지 않는다. 요약 화면에 크게 떠 있기 때문이다. 대신 여정 잔여 거리를 읽는다 — 그 화면에 없는 유일한 정보이고, 방금 뛴 거리가 "지구 한 바퀴" 어디에 쌓였는지 알려주는 자리다.

도시에 도착한 날은 멘트가 바뀐다. 22개 도시에서 딱 한 번씩만 들린다.

목소리는 기기 설정을 따라간다 — 앱이 음성을 따로 싣지 않는다. 삼성헬스도 같은 방식이다.

읽는 속도 살짝 빠르다는 의견이 있어 다른 기기에서 더 들어본 뒤 정한다
음소거 스위치 · 음악 볼륨 음성이 나올 때 음악을 줄이고 얹는다. 음악을 틀어놓고 직접 들어봐야 확인된다
