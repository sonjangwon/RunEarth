## 2. Figma 를 그대로 따르지 않은 2건 (사용자 결정)

### ① 시간의 `.43` — 넣지 않는다

Figma 는 `00:18` 뒤에 1/100초를 작게 붙인다. 그런데 트래커는 **1초 단위로
틱한다**(`run_tracker.dart` `_startElapsedTimer`). 1/100초를 그리려면 화면용
고속 타이머(50ms 이하)를 따로 돌려야 하는데, 이 화면은 포그라운드 서비스로
**몇십 분씩 켜져 있는** 화면이다. 배터리 값이 얻는 것보다 크다.

> 레이아웃은 Figma 그대로 두고 소수 span 만 뺐다. 나중에 넣고 싶으면
> `_LiveStats._item` 에 span 하나만 붙이면 된다.

### ② 일시정지 중 '종료' — 남긴다

Figma 는 일시정지하면 버튼 그리드가 **전체폭 '달리기 재개' 하나로** 바뀐다.
즉 **일시정지 상태에서는 종료를 못 한다.** `run-flow.md` 에는 규정이 없다.

멈춰서 숨 고르다 그대로 끝내는 흐름이 흔한데, 재개를 거쳐야만 끝낼 수 있으면
막다른 길이 된다. **재개(전체폭) + 그 아래 종료** 로 했다 — Figma 의 재개
버튼은 그대로 살리면서 종료 경로를 잃지 않는다.

### 넣지 않은 것: 카운트다운 0 의 `GO!`

Figma 는 0 에서 `GO!` 를 700ms 보여준다. 트래커는 **1 다음 바로 running** 으로
넘어가므로, 넣으려면 상태 머신에 단계를 더하고 시작을 0.7초 늦춰야 한다.
화면이 아니라 **로직 변경**이라 따로 판단이 필요하다. 체크리스트에 남겨뒀다.

## 3. 9/20 결정 ②가 코드에 없었다 — 미세먼지 색

`app_colors.dart` 의 미세먼지 4단계가 **폐기된 에어코리아 표준 색계**였다.
커밋 순서를 보니 원인이 분명하다 — 미세먼지 바(`f7372cb`)를 만든 **뒤에**
Figma 정렬 결정(`3e7035a`)이 나왔고, 그때 코드를 되돌리지 않았다.

에어코리아 색은 '좋음'이 **파랑**, '보통'이 **네온그린**이다. 앱 전체가
네온그린 = 좋다 로 쓰는데 여기서만 네온그린이 '보통'이라 뜻이 어긋났다.
Figma 는 좋음부터 네온그린으로 간다.

| | 전 | 후(Figma) |
|---|---|---|
| 좋음 | `#3B82F6` 파랑 | **`#00E87A`** |
| 보통 | `#00E87A` | **`#F59E0B`** |
| 나쁨 | `#FF5F1F` | **`#F97316`** |
| 매우나쁨 | `#EF4444` | 그대로 |

> **교훈**: 결정을 문서에 적은 날, 그 전에 만든 코드도 같이 훑을 것.
> 문서만 고치면 코드가 조용히 어긋난 채 남는다.

## 4. 🔴 하단 페이드가 구글 로고를 덮었다

Figma 는 지도 하단 80px 을 카드색으로 녹여 패널과 잇는다. 그대로 넣었더니
**구글 로고가 페이드에 먹혔다** — 에뮬레이터 캡처에서 발견. 지도 표시
약관상 로고는 가리면 안 된다.

- 페이드 80 → **64**
- `GoogleMap(padding: EdgeInsets.only(bottom: 56))` 로 **로고를 페이드 위로**

`padding` 은 지도 안쪽 여백이라 로고·컨트롤이 그만큼 올라온다. 카메라
중심도 28px 위로 가지만 이 화면에선 체감되지 않는다.
