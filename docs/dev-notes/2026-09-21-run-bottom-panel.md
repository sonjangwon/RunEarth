## 2. Figma 를 그대로 따르지 않은 2건 (사용자 결정)

### ① 시간의 `.43` — 넣지 않는다

Figma 는 `00:18` 뒤에 1/100초를 작게 붙인다. 그런데 트래커는 **1초 단위로
틱한다**(`run_tracker.dart` `_startElapsedTimer`). 1/100초를 그리려면 화면용
고속 타이머(50ms 이하)를 따로 돌려야 하는데, 이 화면은 포그라운드 서비스로
**몇십 분씩 켜져 있는** 화면이다. 배터리 값이 얻는 것보다 크다.

> 레이아웃은 Figma 그대로 두고 소수 span 만 뺐다. 나중에 넣고 싶으면
> `_LiveStats._item` 에 span 하나만 붙이면 된다.

### ② 일시정지 중 '종료' — 남긴다

Figma 는 일시정지하면 버튼 그리드가 **전체폭 '달리기 재개' 하나로** 바뀐다.
즉 **일시정지 상태에서는 종료를 못 한다.** `run-flow.md` 에는 규정이 없다.

멈춰서 숨 고르다 그대로 끝내는 흐름이 흔한데, 재개를 거쳐야만 끝낼 수 있으면
막다른 길이 된다. **재개(전체폭) + 그 아래 종료** 로 했다 — Figma 의 재개
버튼은 그대로 살리면서 종료 경로를 잃지 않는다.

### 넣지 않은 것: 카운트다운 0 의 `GO!`

Figma 는 0 에서 `GO!` 를 700ms 보여준다. 트래커는 **1 다음 바로 running** 으로
넘어가므로, 넣으려면 상태 머신에 단계를 더하고 시작을 0.7초 늦춰야 한다.
화면이 아니라 **로직 변경**이라 따로 판단이 필요하다. 체크리스트에 남겨뒀다.

## 3. 9/20 결정 ②가 코드에 없었다 — 미세먼지 색

커밋 순서를 보니 원인이 분명하다 — 미세먼지 바(`f7372cb`)를 만든 **뒤에**

에어코리아 색은 '좋음'이 **파랑**, '보통'이 **네온그린**이다. 앱 전체가
네온그린 = 좋다 로 쓰는데 여기서만 네온그린이 '보통'이라 뜻이 어긋났다.
Figma 는 좋음부터 네온그린으로 간다.

| | 전 | 후(Figma) |
|---|---|---|
| 좋음 | `#3B82F6` 파랑 | **`#00E87A`** |
| 보통 | `#00E87A` | **`#F59E0B`** |
| 나쁨 | `#FF5F1F` | **`#F97316`** |
| 매우나쁨 | `#EF4444` | 그대로 |

> **교훈**: 결정을 문서에 적은 날, 그 전에 만든 코드도 같이 훑을 것.
> 문서만 고치면 코드가 조용히 어긋난 채 남는다.

## 4. 🔴 하단 페이드가 구글 로고를 덮었다

Figma 는 지도 하단 80px 을 카드색으로 녹여 패널과 잇는다. 그대로 넣었더니
**구글 로고가 페이드에 먹혔다** — 에뮬레이터 캡처에서 발견. 지도 표시
약관상 로고는 가리면 안 된다.

- 페이드 80 → **64**
- `GoogleMap(padding: EdgeInsets.only(bottom: 56))` 로 **로고를 페이드 위로**

`padding` 은 지도 안쪽 여백이라 로고·컨트롤이 그만큼 올라온다. 카메라
중심도 28px 위로 가지만 이 화면에선 체감되지 않는다.

## 6. 홈 디테일 (체크리스트 4번, `0a882f8`)

### `maxConsec` 은 새 필드가 아니었다

체크리스트에 "`StreakInfo.maxConsec` **필드 추가 필요**"로 적어뒀는데 **잘못
본 것이다.** `StreakDay.consec` 이 이미 날짜별 연속 일수를 들고 있어서, 주간
최대값으로 파생하면 된다. getter 로 넣었다 — 따로 필드를 두면 둘이 어긋날 수
있다. 체크리스트도 바로잡았다.

> 앞 세션이 "필드가 필요하다"고 적어둔 항목은 **그대로 믿지 말고 모델을 한 번
> 열어볼 것.** 이 한 줄 때문에 "데이터 모델 변경이라 물어봐야 한다"고 판단해
> 작업 시작을 한 번 미뤘었다.

### 진행바는 직접 그려야 했다

`LinearProgressIndicator` 로는 **마커를 바 밖으로 못 내보낸다.** Figma 의 흰 점
마커(12)가 바(6)보다 커서 위아래로 삐져나오는 구조라, `LayoutBuilder` +
`Stack` 으로 직접 그렸다. 채움도 단색에서 `#00A854 → #00E87A` 그라데이션으로.

### 스트릭 카드는 '최고 연속 색'이 기준이다

이번 주 최고 연속 일수의 색 하나가 카드 전체를 지배한다 — 🔥 크기와 glow,
카드 배경 radial glow, 오늘 점, 오늘 날짜 글자색이 전부 이 색을 따른다.
연속이 쌓일수록 카드가 초록 → 주황 → 핫핑크로 달아오른다.

**Figma 대로 못 한 것**: 원 안쪽 `inset` 그림자. Flutter `BoxShadow` 에는
inset 이 없어 바깥 glow 만 넣었다.

**불꽃 크기 기준값을 바꿨다**: Figma `11 + maxConsec×1.4` → `15 + maxConsec×1.4`.
구현이 이미 15 였고, Figma 값을 그대로 쓰면 **연속 0일일 때 지금보다 작아진다.**
앱 전체 글자가 Figma보다 한 단계 큰 것과 같은 맥락이다.

### 9/20 결정 ①도 코드에 없었다 — 스트릭 7일 색

`#EF4444` → `#FF2D55`. 기존 값은 **미세먼지 '매우나쁨'과 같은 색**이라, 한 주를
다 채운 보상이 경고색으로 보였다. 코드 + `CLAUDE.md` + 기능정의서 2곳 +
`streak.md` **네 곳**을 같이 고쳤다.

> §3 의 미세먼지 색과 **똑같은 사고**가 반복됐다. 9/20 에 결정 ①②를 문서에
> 적으면서 코드는 안 고쳤다. 결정을 적은 날 코드도 같이 훑었어야 했다.

### 검증하려고 가짜 데이터를 꽂았다 — 되돌릴 때 실수

실제 데이터가 1일 연속뿐이라 4~7일 연속 모습과 '오늘 미달성 점'을 볼 수
없었다. 임시로 `_StreakCard` 두 개를 더 붙여 찍고 되돌렸다.

**되돌린 뒤 기기에 다시 설치하는 걸 빠뜨렸다.** `flutter analyze` 가
통과하니 끝난 걸로 처리하고 커밋까지 했는데, 에뮬레이터에는 미리보기 APK 가
그대로 남아 스트릭 카드가 3개 보이는 걸 사용자가 발견했다. 커밋된 코드는
멀쩡했지만 화면과 소스가 달랐다.

> **임시 코드는 "되돌리기 + 재설치"까지가 한 세트다.** 정적 분석 통과는
> 기기 상태를 보장하지 않는다.

## 7. 콘텐츠 (체크리스트 5번, `97251d4`)

### 테마 카드 — 사진이 글자에 가려지고 있었다

이모지·제목·설명·거리가 **전부 사진 위에 겹쳐** 있었다. Figma 는 사진(80) 위엔
이모지와 이름만 두고 나머지를 아래 행으로 내린다. 그래야 사진이 보인다.
우상단 90px 거대 워터마크 이모지도 뺐다.

### 마라톤 카드 — 한 덩어리를 두 행으로

통계행(상단 구분선: 참여자 수 · 내 순위) + 상품행(상품 · 참여 pill). CTA 는
전체폭 버튼에서 pill 로 줄었다 — 참여 전은 옅은 테두리, 참여 중은 꽉 찬
네온이라 이미 들어간 대회가 한눈에 도드라진다.

### 전수 조사가 놓친 2건 (사용자 승인 후 같이)

| | 놓친 것 |
|---|---|
| 탭 바 | 네온 pill 두 개 → 한 덩어리 세그먼트(선택 시 `bg-card` + 테두리) |
| 종료 대회 | 카드째 `opacity 60%` — 전에는 D-day 뱃지만 흐려졌다 |

> 9/20 의 "전수 조사"가 완전하지 않았다. **화면을 실제로 열어 Figma 와 나란히
> 볼 때 더 나온다.** 7번 프로필도 "큰 차이 없음"으로 적혀 있지만 같은 이유로
> 믿을 수 없다 — 아직 비교를 안 했다.

### ⚠️ 종료된 대회 모습은 확인 못 했다

`content_sample_data.dart` 에 `ended: true` 인 대회가 없어서
`opacity 60%` + '종료' 뱃지 + CTA 숨김 경로가 한 번도 안 그려진다.
샘플에 하나 넣거나 실제 데이터가 생길 때 확인할 것.
