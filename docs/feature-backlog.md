## 완료 조건 감사 (2026-09-25)

각 문서의 '완료 조건' 체크박스가 실제 구현과 맞는지 전수 대조했다. **하루에
다섯 번이나 "다 만들어놓고 체크를 안 한" 경우가 나와서** 전체를 확인했다.

**결과: 68개 미체크 → 55개.** 13개가 실제로는 끝나 있거나 조건 자체가 낡아 있었다.

| 처리 | 수 | |
|---|---|---|
| 실제로 완료 → 체크 | 10 | 인사말 4단계 · 기록 빈 상태 · 오프라인 배너 · 백그라운드 추적 · 스냅샷 복원 · 일시정지 거리 제외 · 경로 렌더 대표이미지 · 테마 상세 진입 · 테마에 경쟁요소 없음 · 세션 가드 |
| 조건이 낡음 → 정정 | 3 | 위치 권한 시점(로그인 직후 → **START**) 2건 · "안 하기로 한 것"이 미완료로 보이던 것 1건 |
