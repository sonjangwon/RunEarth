# Run Earth 개발 현황 공유 (팀 공유용)

**작성일** 2026-09-27 · **기간** 2026-08-22 ~ 2026-09-27 (약 5주)

**대상** 팀 전체 — 기획 · 디자인 · 콘텐츠 · 개발

MVP 화면·기능은 **대부분 구현이 끝났고**, 지금은 **실기기 검증과 GPS 정확도 확인**
단계다. 남은 병목은 코드보다 **에셋 · API 키 · iOS 빌드 환경**이다.

> 이 문서의 스크린샷은 **2026-09-27 갤럭시 S24 · 갤럭시 노트8 실기기**에서 찍은
> 것이다. 시뮬레이터나 디자인 시안이 아니라 **지금 설치하면 보이는 화면**이다.
> 근거·수치·의사결정 기록은 `docs/dev-notes/` 의 날짜별 노트에 있다.

### 2-2. 홈 — 지구 한 바퀴 여정

앱의 핵심 컨셉이 사는 화면이다. **달린 거리가 그대로 여정 진행도가 된다.**
서울0 → 인천27 → 전주194 → 부산325km → 해외 G20 수도 18개
(베이징952km ~ 부에노스아이레스19,432km), **총 22개 도시**.

:::figs
![갓 시작한 계정 — 서울→인천 구간, 2.6km](../assets/screenshots/2026-09-27/03-home-journey-seoul-incheon.jpg)
![쌓인 계정 — 인천→전주 구간, 48.5km](../assets/screenshots/2026-09-27/04-home-journey-incheon-jeonju.jpg)
:::

같은 화면이 진행도에 따라 어떻게 달라지는지 두 계정을 나란히 놓은 것이다.

- **여정 카드** — 현재 구간(`서울 → 인천`), 우상단에 **다음 도시까지 남은 거리**,
  아래에 구간 진행 바와 도시 점 5개. 지나온 도시는 체크, 현재 도시는 속 찬 원이다.
- **배경 이미지가 도시마다 바뀐다.** 왼쪽은 인천(송도 야경), 오른쪽은 전주(한옥마을).
  지금 이미지는 전부 **Unsplash 임시본**이다 (3번 참조).
- **통계 3칸** — 총 거리 · 총 시간 · 총 횟수.
- **스트릭** — 주간 7칸. 달린 날에 네온그린 체크가 들어가고, 우측에 `5주 연속`.

### 2-3. 달리기 — 앱에서 가장 많이 만든 곳

:::figs
![출발 전 — GPS · 러닝 타입 · 날씨 · 미세먼지](../assets/screenshots/2026-09-27/08-run-ready.jpg)
![달리는 중 — 실시간 지도와 경로](../assets/screenshots/2026-09-27/09-run-tracking-map.jpg)
:::

START → **3초 카운트다운** → 추적 → 일시정지/재개 → 종료까지 상태 머신이 완성돼 있다.

- **출발 전**(왼쪽) — `● GPS 연결됨` 을 먼저 확인시키고, **러닝 타입**(일반 / 테마 /
  온라인), **날씨**, **미세먼지**를 보여준 뒤 `달리기 시작`.
  **날씨 28°C 맑음 · 미세먼지 42 보통은 샘플 값이다** — API 키가 아직 없다 (3번 2항).
- **달리는 중**(오른쪽) — 좌상단 `● GPS 기록 중` 으로 신호 상태를 항상 보여준다.
  지도는 **Google Maps 다크 스타일**이고, 경로 선이 실시간으로 그려진다.
  하단에 **시간 · 거리 · 페이스**, 그 아래 `일시정지` / `종료`.
- **화면을 끄거나 앱을 내려도 계속 추적한다** (안드로이드 포그라운드 서비스 + 알림).
- **앱이 강제 종료돼도 진행 중이던 러닝을 복원한다.**
- **음성 안내** — 출발 · 1km마다 · 종료를 읽어준다 (5번 참조).

#### 종료 직후 요약

:::figs
![요약 상단 — 직접 찍은 사진 위에 기록](../assets/screenshots/2026-09-27/10-run-finish-photo.jpg)
![요약 하단 — 경로와 1km 구간 페이스](../assets/screenshots/2026-09-27/11-run-finish-splits.jpg)
:::

- 위: **대표 이미지**. 달리는 중 찍은 사진 위에 거리·페이스·시간과 **경로 선**,
  그리고 `RUN EARTH · 2026.09.26` 워터마크가 얹힌다. 사진을 안 찍었으면 경로
  그림만 나오는 모드로 전환된다.
- 아래: **상세 기록 6칸**과 **1km 구간별 페이스 막대**. 위 예시는 20분 2.41km를
  네 구간으로 자동 분할했다.
- **칼로리 · 평균 심박수 · 케이던스는 비어 있다.** 칼로리는 **체중 입력**이,
  심박수·케이던스는 **웨어러블 연동**이 있어야 채워진다 (둘 다 아직 없음).

### 2-4. 기록 — 지난 러닝 다시 보기

:::figs
![전체 — 네온그린](../assets/screenshots/2026-09-27/12-records-list-all.jpg)
![일반 — 네온그린](../assets/screenshots/2026-09-27/13-records-list-normal.jpg)
![테마 — 파랑](../assets/screenshots/2026-09-27/14-records-list-theme.jpg)
![온라인 — 노랑](../assets/screenshots/2026-09-27/15-records-list-online.jpg)
:::

목록 맨 위에 **기간 요약**(총 거리 · 총 시간 · 총 횟수)이 있고, 그 아래 `전체` ·
`일반` · `테마` · `온라인` 필터가 있다.

**필터를 바꾸면 요약 카드의 숫자 색이 같이 바뀐다.** 일반은 네온그린, 테마는 파랑,
온라인은 노랑 — 목록 안의 타입 뱃지와 **같은 색**이다. 숫자만 바뀌면 "지금 무엇을
보고 있는지"가 한 박자 늦게 읽혀서, 색을 묶었다.

목록은 월별로 묶이고 각 줄에 **경로 썸네일 · 날짜 · 타입 뱃지 · 거리 · 시간 ·
페이스 · 칼로리**가 들어간다. 실제로 뛴 일반 러닝은 칼로리가 `--` 로 비어 있다.

#### 기록 상세

:::figs
![낮 러닝 0.72km](../assets/screenshots/2026-09-27/16-records-detail-day-photo.jpg)
![같은 기록 아래쪽](../assets/screenshots/2026-09-27/17-records-detail-day-splits.jpg)
![밤 러닝 2.41km](../assets/screenshots/2026-09-27/18-records-detail-night-photo.jpg)
![같은 기록 아래쪽](../assets/screenshots/2026-09-27/19-records-detail-night-splits.jpg)
:::

기록 상세는 종료 요약과 같은 구성을 쓰되 두 가지가 더 있다.

- 우상단 **`일반` 뱃지** — 러닝 타입이다.
- 우상단 **카메라 버튼** — 나중에도 대표 사진을 바꿀 수 있다.
- **오프라인에서도 조회된다.** 로컬 DB가 1차 저장소라 서버 없이 열린다.

낮/밤 두 건을 같이 넣은 이유는, **사진이 밝든 어둡든 흰 글씨와 네온그린 경로가
읽히는지**가 이 화면의 유일한 위험이기 때문이다. 두 경우 모두 읽힌다.

## 5. 음성 안내 — 구현 완료 (9/27)

출발할 때와 1km마다, 종료할 때 음성으로 알려준다. **기기에 내장된 음성 합성을
쓰므로 추가 서버도, 비용도, 네트워크도 필요 없다.** 오프라인 러닝에서도 동작한다.

| 시점 | 멘트 | 길이 |
|---|---|---|
| 출발 | "러닝을 시작합니다" | 1.4초 |
| 1km | "1킬로미터, 6분 28초" | 2.2초 |
| 2km부터 | "2킬로미터, 구간 6분 28초, 평균 6분 41초" | 4.3초 |
| 종료 | "러닝을 종료합니다. 전주까지 142.6킬로미터 남았습니다" | 5.1초 |
| 도시 도착 | "러닝을 종료합니다. 전주에 도착했습니다" | 3.4초 |

**종료 때 거리·시간을 읽지 않는다.** 요약 화면에 크게 떠 있기 때문이다. 대신
**여정 잔여 거리**를 읽는다 — 그 화면에 없는 유일한 정보이고, 방금 뛴 거리가
"지구 한 바퀴" 어디에 쌓였는지 알려주는 자리다. **도시에 도착한 날은 멘트가
바뀐다.** 22개 도시에서 딱 한 번씩만 들린다.

목소리는 **기기 설정을 따라간다** — 앱이 음성을 따로 싣지 않는다.

**남은 것**: 읽는 속도가 살짝 빠르다는 의견이 있어 **다른 기기에서 더 들어본 뒤**
정한다. 음소거 스위치와 음악 볼륨 처리도 남아 있다. **iOS는 Mac이 없어
검증하지 못했다.**

## 6. 참고 — 기술 스택

- **Flutter** (iOS · Android 공용 코드)
- **Supabase** (로그인 + DB + 권한 + 파일 저장) — MVP는 별도 서버 없이 운영
- 로컬 DB **drift** / 상태관리 **Riverpod** / 지도 **Google Maps**
- **local-first**: 로컬 DB가 1차 진실 소스 → 서버 업로드는 뒤따라 처리.
  **비행기 모드에서 뛰어도 기록은 안 사라지고**, 연결되면 자동 업로드된다
- 문서가 단일 출처: 로직·규칙은 `docs/features/*.md`, 화면·비주얼은 Figma
